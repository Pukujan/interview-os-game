# Interview OS Game

Interview OS Game is a personal, non-commercial mobile learning game for technical interview preparation. It focuses first on mid-level Applied AI engineering while supporting DSA, ML fundamentals, system design, and technical diagnosis.

This repository is being projectized using `Pukujan/project-assurance-modules` before implementation. The initial product thesis is a fun, progression-based interview game that combines concise questions, scenario decisions, typed reasoning, progressive hints, jargon tooltips, dataset-backed evaluation where useful, and longitudinal learning evidence via Study OS.

Implementation is intentionally deferred until the initial scope, reuse boundary, system design, invariants, failure register, benchmark policy, and first vertical slice are frozen.
