# Product and Learning Invariants Draft

- XP, streaks, and level unlocks are game state, not mastery evidence.
- A tooltip may define terminology but must not reveal the solution path.
- Assistance use is recorded and preserved in learner evidence.
- Practice-visible items cannot later count as unseen transfer evidence.
- LLM output is never the sole oracle when deterministic, executable, dataset-grounded, or human-authored evidence exists.
- A mission must state what capability it is intended to test.
- Dataset-backed evaluation must identify the dataset/protocol revision or immutable source identity where practical.
- Interview OS owns gameplay and mission interaction; Study OS remains the preferred owner for longitudinal learning evidence and capability-state semantics.
- The first vertical slice must remain usable without a full general-purpose simulation/run-bench platform.
- Visual interaction must support the learning action rather than merely decorate the question.
