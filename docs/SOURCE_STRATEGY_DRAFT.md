# Source and dataset strategy draft

Interview OS will distinguish curriculum sources from empirical evaluation fixtures.

- Curriculum/reference sources may inform authored questions, explanations, and concept definitions.
- Dataset-backed missions must pin exact dataset/protocol identities where practical.
- Practice-visible material must not be relabeled as unseen transfer evidence.
- Hidden/confirmatory material, when used, must remain outside client bundles and normal authoring prompts.
- LLM reasoning evaluation is advisory within explicit rubrics; deterministic or dataset-grounded evidence remains authoritative where available.

This draft will be reconciled with PAM benchmark integrity requirements during preflight.
